# Kurali All 项目协作仓库

这是一个多人协作的 OpenClaw 项目仓库，用于展示分支协作的工作流程。

## 分支说明

本项目包含三个分支，分别对应三位协作成员：

1. **yuanbao** - 元宝的工作分支
2. **wudao-bot** - 無道的Bot的工作分支
3. **silverkurali-bot** - SilverKurali的Bot的工作分支

## 协作流程

1. 每位成员在自己的分支上进行工作
2. 定期查看其他分支的代码变更
3. 通过 Pull Request 或合并操作进行代码整合
4. 保持主分支（master）作为稳定版本

## 当前仓库内容

- OpenClaw 工作空间配置
- 多种技能文件（Agent Skills）
- 项目配置文件

## 使用说明

1. 克隆仓库：`git clone https://gitee.com/AY77-OP/kurali-all`
2. 切换分支：`git checkout <branch-name>`
3. 查看其他分支：`git checkout <other-branch>`
