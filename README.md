# Kurali All Shell Skills Repository

这是一个专注于 Shell/CLI 技能的 OpenClaw 项目仓库。

## 包含的技能

1. **agent-browser** - 基于 Rust 的无头浏览器自动化 CLI
2. **find-skills** - 帮助发现和安装 AgentSkills
3. **github** - GitHub CLI 集成技能
4. **obsidian** - Obsidian vault 操作技能
5. **openclaw-tavily-search** - Tavily API 网络搜索
6. **summarize** - URL/文件摘要 CLI
7. **tencent-cos-skill** - 腾讯云对象存储技能
8. **tencent-docs** - 腾讯文档操作技能
9. **tencent-meeting-mcp** - 腾讯会议操作技能
10. **weather** - 天气查询技能

## 核心配置文件

- `AGENTS.md` - 代理配置和工作空间指南
- `SOUL.md` - 身份和人格定义
- `USER.md` - 用户信息
- `IDENTITY.md` - 身份定义
- `TOOLS.md` - 工具配置
- `HEARTBEAT.md` - 心跳配置
- `BOOTSTRAP.md` - 启动配置

## 使用说明

```bash
# 克隆仓库
git clone https://gitee.com/AY77-OP/kurali-all

# 查看可用技能
ls skills/
```
